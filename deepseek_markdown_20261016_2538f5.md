# GeoChange Monitor

Веб-ориентированная система автоматического обнаружения изменений
объектов инфраструктуры на спутниковых изображениях с использованием
методов глубокого обучения.

## Что делает система

- принимает пару спутниковых снимков одной территории за разные даты;
- формирует маску изменений с помощью нейросетевой модели
  битемпоральной сегментации;
- применяет постобработку для удаления шумовых срабатываний;
- векторизует найденные объекты и рассчитывает их площади и координаты;
- отображает результаты на карте через веб-интерфейс;
- формирует отчёт в CSV/PDF.

## Стек

- Python 3.11
- PyTorch (Siamese U-Net / ChangeFormer / BIT)
- Rasterio, OpenCV, NumPy — работа с геопривязанными растрами
- GeoPandas, Shapely — векторизация результатов
- FastAPI — REST API инференса
- Streamlit + Leaflet — веб-интерфейс и карта
- SQLite — метаданные и логи предиктов

## Датасет

Обучение и оценка — на открытом датасете **LEVIR-CD**
(637 пар снимков высокого разрешения, разметка по зданиям).
Дополнительная проверка обобщающей способности — на **WHU-CD**.

## Быстрый старт

```bash
git clone <repo-url>
cd geochangemonitor
pip install -r requirements.txt

# обучение модели
python train.py --config configs/siamese_unet.yaml

# запуск веб-интерфейса
uvicorn app.main:app --reload
streamlit run app/ui.py
