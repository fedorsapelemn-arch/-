# Выбор моделей: GeoChange Monitor

## 1. Baseline — классические методы

| Метод                | Условие / формула                              | Особенность                    |
|----------------------|------------------------------------------------|--------------------------------|
| Пиксельная разность  | `diff = abs(img1 - img2)`, порог              | Быстро, но шумно               |
| NDVI-разность        | `NDVI = (NIR - Red) / (NIR + Red)`, разность  | Хорошо для растительности      |
| NDBI-разность        | `NDBI = (SWIR - NIR) / (SWIR + NIR)`          | Для застроенных территорий     |
| SSIM                 | `1 - SSIM(img1, img2)`                        | Устойчив к освещению           |
| CVA + KMeans         | Change Vector Analysis + кластеризация        | Многоклассовые изменения       |

**Вывод:** baseline не требует обучения, готов к запуску немедленно, используется как Cold-Start fallback и точка сравнения для нейросети.

## 2. Сравнение ML-моделей (Фаза 1: классические признаки + sklearn)

| Модель                       | RAM (fit)  | Время обучения | Инференс | Интерпр. |
|------------------------------|------------|----------------|----------|----------|
| RandomForestClassifier       | ~50–120 МБ | 30–120 с       | <50 мс   | Высокая  |
| GradientBoostingClassifier   | ~40–100 МБ | 60–240 с       | <80 мс   | Средняя  |
| XGBClassifier                | ~30–80 МБ  | 30–120 с       | <30 мс   | Средняя  |
| SVM (RBF)                    | ~20–60 МБ  | 60–300 с       | <100 мс  | Низкая   |
| LogisticRegression           | <10 МБ     | <10 с          | <5 мс    | Высокая  |

**Признаки для Фазы 1:** значения каналов, NDVI, NDBI, локальная дисперсия, градиенты, текстурные признаки (GLCM).

**Итог Фазы 1:** RandomForestClassifier на пиксельных признаках. Причина: устойчивость к выбросам, интерпретируемость, низкие требования к RAM.
